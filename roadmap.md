# Roadmap

- [x] Intégrer l’agenda interactif dans Deep Work.
- [x] Remplacer les durées fixes par une molette de 1 à 180 minutes.
- [x] Valider la durée personnalisée, la création et le redimensionnement d’un bloc sur ordinateur et mobile.
- [x] Créer et valider la célébration plein écran de chaque nouvelle performance.
- [x] Ajouter et valider une signature sonore synchronisée à la célébration de rang.
- [x] Remplacer la signature mélodique par un impact grave et métallique plus adapté à Eclipse Flow.
- [x] Auditer et corriger tous les débordements horizontaux sur smartphone.
- [x] Fiabiliser les gestes tactiles des roulettes et de l’agenda sans bloquer le défilement vertical.
- [x] Harmoniser les marges latérales et l’empilement des contenus sur écrans étroits.
- [x] Valider chaque espace principal sur smartphone et vérifier l’absence de débordement global.
- [x] Forcer une vraie mise en page téléphone en colonne unique lorsque le mode Mobile est sélectionné.
- [x] Étendre le conteneur principal sur toute la largeur mobile sans bandes latérales.
- [x] Stabiliser le mode Mobile dès le premier rendu d’une session déjà active.
- [x] Renforcer le mode Mobile avec un empilement vertical strict et une typographie plus confortable.
- [x] Verrouiller durablement l’affichage Mobile sur les téléphones, indépendamment de la session restaurée.
- [x] Contraindre strictement la coque et la barre mobile après reprise de session, zones sûres incluses.
